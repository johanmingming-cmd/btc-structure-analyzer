# BTC Structure Analyzer

Android app for BTC/USDT market-structure analysis across 5m, 15m, and 1h timeframes.

## Current status

Starter scaffold. The current implementation is an early prototype and has not yet been verified by a successful Android build or on-device testing.

## Planned features

- Dark dashboard
- Binance public candlestick data
- HH / HL / LH / LL swing-structure baseline
- Multi-timeframe interpretation (1h bias, 15m context, 5m short-term movement)
- Later phases: true candlestick chart, local history, notifications, and background monitoring

## Build

Open this project in Android Studio and allow Gradle sync. A compatible Android SDK and network access for dependency resolution are required.

Do not treat the prototype's structure labels as trading advice or as validated predictions.
